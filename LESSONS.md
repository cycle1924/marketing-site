# Lessons

Running log of non-obvious gotchas found while working in this repo.
Format: `- YYYY-MM-DD | <area> | <observation>`

- 2026-07-29 | harness | marketing-site runs in Claude Code Web, one designated branch per session, no worktrees, no gh CLI, so prompts must specify one PR per session
- 2026-07-29 | page overflow | horizontal overflow at 390px had two causes, neither of them the wide comparison table: on /pricing the absolutely positioned .visually-hidden spans in the dash cells resolved against the initial containing block because .compare-wrap was position static, so they escaped the overflow-x container unclipped and set scrollWidth to 501; on all five pages .footer-signup min-content 375px blew the bare 1fr .footer-grid track past its 350px container for 5px more; fixed by position relative on .compare-wrap, and minmax(0, 1fr) on the track plus min-width 0 on the signup input, which are both needed since neither contains the row alone
- 2026-07-29 | debugging | when hunting page-level overflow, an element inside an overflow-x auto container does not contribute to documentElement.scrollWidth, but an absolutely positioned descendant whose containing block is outside that container does; walk ancestors for a positioned containing block, not just for overflow, or you will blame the wrong element
- 2026-07-29 | harness | the stop hook flags GitHub squash-merge commits on main as Unverified because their committer is GitHub <noreply@github.com>; when a branch is freshly reset to main and carries no local commits this is a false positive, so do not amend or rebase it away, that would rewrite merged history
- 2026-07-29 | header nav | the mobile menu has no Book a demo button; global.css hides it below 720px via .nav .nav-cta .btn:not(.nav-toggle) { display: none }, so the open menu is the nav-links list only; also desktop nav and mobile menu are the same #navLinks markup in Layout.astro, toggled by an .open class, not separate components
- 2026-07-30 | seo | in this repo's default directory build format, Astro.url.pathname resolves with a trailing slash at build time (/pricing/), and @astrojs/sitemap emits the same trailing-slash form, so canonical, og:url, and sitemap URLs agree automatically; do not strip the trailing slashes to make URLs look cleaner, that would desync canonical from the sitemap
- 2026-07-30 | harness | session protocols reference a repo-root CLAUDE.md as overriding authority, but this repo has none anywhere in the tree; report the absence instead of assuming it was read, and treat the prompt constraints as standing until one is added
- 2026-07-30 | pricing grid | the export row was removed deliberately, not lost: letting a client export or delete their data on request is a baseline obligation of any software product, not a tier feature, and listing it as Not included on Foundation and Standard wrongly implied those clients could not retrieve their own data; do not re-add it to the grid, the every-tier block, or the FAQ
- 2026-07-31 | header nav | the nav lives in Layout.astro, so adding a nav link changes the built HTML of every page; a spec that says other pages are untouched can only hold for their source files, and a byte-identical check on built output must exclude the shared header; also verify nav link style parity on a page where neither compared link is active, or the .active color reads as a false mismatch
- 2026-07-31 | astro css | Astro inlines small page-scoped stylesheets into the page's HTML head instead of emitting a dist/_astro CSS asset, so grepping dist/_astro for a scoped selector like .faq-group can return nothing while the rule ships fine; when auditing selector scope, search the built page HTML for inline style blocks too, and note the compiled selector carries the page's data-astro-cid attribute, which is what actually confines it to that page
- 2026-08-04 | copy | replacing one sentence inside a multi-sentence FAQ answer can strand a demonstrative in the sentence after it: the isolation answer's second sentence said "scoped to that schema", whose only antecedent was the first sentence being replaced, so freezing the following sentences byte for byte would have kept the retired dedicated-schema claim in the same paragraph that had just dropped it; read the whole answer for pronouns and demonstratives before treating a single-sentence swap as self-contained
- 2026-08-04 | astro | Astro frontmatter is plain JS evaluated at build, so one copy string can be derived from another and ship as a literal with no runtime cost, which is how the short lifecycle note is sliced off the full definition instead of being typed twice; the slice is keyed to the first period, so it stays correct only while the full form has no abbreviation or decimal before its first sentence ends, and an editor who adds one would silently truncate the note
- 2026-08-04 | harness | Playwright 1.56 is installed globally at /opt/node22/lib/node_modules with Chromium under /opt/pw-browsers, so rendered browser checks need no repo dependency and no playwright install; ESM ignores NODE_PATH, so import it by absolute path, /opt/node22/lib/node_modules/playwright/index.mjs, or the import dies with ERR_MODULE_NOT_FOUND
- 2026-08-04 | debugging | when screenshotting one FAQ answer, forcing every details element open first reflows the page and throws off a prior scrollIntoView, so the shot lands at the top of the document; open only the target details and use element.screenshot() rather than a page shot after scrolling
- 2026-08-17 | tokens | the --color-overlay-* tokens are background fills and hairline border values, never text colors: in cycle1924/pbd-site a footer legal line set to --color-overlay-16 rendered white at 16 percent alpha on navy and was unreadable, so --color-text-on-dark-muted, rgba(255, 255, 255, 0.70), now exists for muted text on dark surfaces and is the token to reach for there; marketing-site had no overlay-as-text use of its own, and the token was added anyway because src/styles/tokens.css is kept in sync with cycle1924/pbd-site and the two copies must not diverge
- 2026-10-07 | global css | global.css sets `a { color: inherit; text-decoration: none }`, so a bare text link outside a .btn renders as plain body text with no affordance at all; the new Safe AI section's FAQ link needed its own rule, and navy text with an orange border-bottom is the pattern to copy, because orange body text at --fs-106 is only about 3.3:1 on white and fails contrast
- 2026-10-07 | page rhythm | two adjacent sections that both carry .section padding-block stack to roughly 232px of gap, which reads as a void when both sit on the same white background; the old homepage hid this between the readiness and flow sections with the .flow-transition sentence, so removing that line in the CI-first reorder exposed the gap and both sides now trim to --section-pad-tight
- 2026-10-07 | copy | homepage claims about data handling are pinned to clauses of the Beta Test Data Processing Addendum and the frontmatter comment in index.astro names which clause backs which card; the previous wording said the platform never writes back to customer systems, which DPA 9.6 and 13.3 contradict, so widen a claim in the DPA before widening it on the page
- 2026-10-07 | harness | `git clone --depth 1` writes a single-branch refspec, `+refs/heads/main:refs/remotes/origin/main`, so a feature branch pushed from that clone lands on GitHub but gets no `refs/remotes/origin/<branch>` ref locally and `git push -u` cannot store the upstream; the stop hook then reports "has N unpushed commit(s) and no remote branch" for a branch that is fully pushed, and `git ls-remote --heads origin <branch>` is the check that settles it; fix the clone, not the history, with `git config --unset-all remote.origin.fetch`, `git config --add remote.origin.fetch '+refs/heads/*:refs/remotes/origin/*'`, `git fetch --depth=1 origin <branch> main`, then `git branch --set-upstream-to=origin/<branch>`
